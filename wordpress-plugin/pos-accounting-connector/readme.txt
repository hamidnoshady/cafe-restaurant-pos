اتصال امن و دوطرفهٔ فروشگاه ووکامرس به سامانهٔ فروش و حسابداری.

== Description ==

این افزونه فروشگاه ووکامرس شما را به سامانهٔ حسابداری متصل می‌کند:

* **از فروشگاه به حسابداری:** سفارش، برگشت وجه، محصول و مشتری.
* **از حسابداری به فروشگاه:** موجودی انبار و قیمت.

همهٔ ارتباط‌ها از سمت وردپرس آغاز می‌شود؛ سامانهٔ حسابداری هیچ‌گاه به فروشگاه شما
وصل نمی‌شود. بنابراین فروشگاهی که پشت فایروال است یا آدرس ثابت ندارد هم بدون
تنظیم اضافه کار می‌کند.

= امنیت =

هر درخواست علاوه بر توکن، دارای مهر زمانی، شمارهٔ یک‌بارمصرف و امضای
HMAC-SHA256 روی متن دقیق درخواست است. توکن فقط برای همین اتصال معتبر است و
هر زمان می‌توانید آن را از پنل حسابداری تعویض کنید.

== Installation ==

1. پوشهٔ افزونه را در `wp-content/plugins/` قرار دهید و آن را فعال کنید.
2. در پنل حسابداری به «اتصال‌ها ← فروشگاه ووکامرس» بروید، یک اتصال از نوع
   «افزونهٔ وردپرس» بسازید و توکن نمایش‌داده‌شده را کپی کنید.
3. در وردپرس به «ووکامرس ← اتصال حسابداری» بروید، آدرس سامانه و توکن را وارد
   کنید، «همگام‌سازی فعال باشد» را بزنید و ذخیره کنید.
4. «آزمایش اتصال» را بزنید.

== Frequently Asked Questions ==

= همگام‌سازی هر چند وقت اجرا می‌شود? =

هر پنج دقیقه، از طریق WP-Cron. چون WP-Cron با بازدید سایت اجرا می‌شود، در
سایت‌های کم‌بازدید بهتر است یک cron واقعی روی `wp-cron.php` تنظیم کنید.

= اگر سامانهٔ حسابداری در دسترس نباشد چه می‌شود? =

سفارش‌ها در صف افزونه می‌مانند و در اولین اجرای موفق ارسال می‌شوند. هیچ سفارشی
از دست نمی‌رود.
